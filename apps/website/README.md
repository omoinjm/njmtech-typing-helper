# website/

Static marketing site for **Typing Helper** — plain HTML/CSS/JS, no build step. Deployed to GitHub Pages by `.github/workflows/deploy-pages.yml` on every push to `main` that touches this folder, at the custom domain in `CNAME` (`typing.njmtech.co.za`). Icons are rendered from `apps/extension/assets/icon.svg` by `pnpm icons`.
