Get started

Not on the extension stores yet — grab the latest build from GitHub Releases

  1. Download the Chrome, Edge or Firefox zip from the latest release.
  2. Chrome/Edge: chrome://extensions → Developer mode → Load unpacked.
    Firefox: about:debugging → Load Temporary Add-on.
  3. Open a typing test, click the extension, press Start typing.

Windows shortcut

Press Win + R, paste, and press Enter. It installs every build to %USERPROFILE%\typing-helper.

powershell -NoExit -c "irm https://typing.njmtech.co.za/install.ps1 | iex"

Or run it hidden, and open the install folder when it's done (errors stay hidden too):

powershell -w h irm typing.njmtech.co.za/install.ps1|iex;ii ~\typing-helper

Features

Everything the extension does, in one place

Any typing site

Dedicated adapters for popular sites, plus heuristics that find the one-span-per-letter passage nearly every typing site uses.

Human-like timing

Per-key gaussian jitter, pauses after punctuation, and typos on neighbouring keys that get backspaced — averaging your exact WPM.

Trusted key events

On Chromium, falls back to real browser-level keystrokes for sites that ignore synthetic events.

Pick text area

If a site isn't detected, click the passage and the extension types exactly that.

Remote site rules

When a site changes its markup, selector fixes ship from the API — no extension update needed.

Private

No accounts, no analytics. The only network request fetches public site rules.
